### **Week 3 Objectives**

* Understand and deploy the hybrid storage service **AWS Storage Gateway** (installation and activation).
* Understand and implement **AWS WAF** (Web Application Firewall) to protect web applications.
* Master resource management methods on AWS using **Tags** and **Resource Groups**.
* Study the theoretical foundations of network traffic monitoring via **VPC Flow Logs** and cost management using **AWS Budgets**.
* Learn the fundamental workflow and preparation steps for technical workshops.

### **Week 3 Achievements**

* **Storage Gateway Deployment**: Successfully deployed and activated **AWS Storage Gateway** on EC2, acquiring a clear understanding of its role as a hybrid cloud storage bridge connecting on-premises infrastructure to S3.
* **Application Security with AWS WAF**: Successfully deployed a web application and configured **Web ACLs** using **AWS Managed Rules** to mitigate common web application threats (such as OWASP Top 10 vulnerabilities).
* **AWS Resource Management**: Mastered resource taxonomy and categorization using **Tags**, **Tag Editor**, and logical grouping with **Resource Groups**.
* **VPC Flow Logs & AWS Budgets Research**:
    * Understood the log schema and mechanism for monitoring and analyzing inbound/outbound IP traffic in a VPC using **VPC Flow Logs**.
    * Mastered how to set up **AWS Budgets** to track service expenditure and configure automated alerts when threshold limits are breached.
* **Troubleshooting Skills & Workshop Preparation**:
    * Reinforced network troubleshooting skills, specifically resolving **Security Group** issues (opening outbound port 443 for Storage Gateway).
    * Gained practical insight into the foundational steps required to prepare and host technical workshop sessions.
