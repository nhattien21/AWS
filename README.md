# TechMart Electronics Store

A modern electronics storefront built with Hugo, reworked from the original AWS workshop project into a clean online shop landing page.

## Live demo

- GitHub Pages: https://nhattien21.github.io/AWS/
- Local preview: `hugo server`

## Highlights

- Hero section with promotional banner
- Best-selling product cards
- Category navigation
- Customer reviews and trust signals
- Newsletter signup
- English and Vietnamese language support
- Responsive static site layout

## Project structure

```text
AWS/

```

## Run locally

```bash
hugo server -D --bind 0.0.0.0 --baseURL=http://localhost
```
